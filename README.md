# React Native Nutrition Project. 
We created a react native app for planning nutrition. The commits and more details can be seen in the project that I forked from my student account.

# Main Functionality. 

## Recepie Builder. 
The app allowed users to create recepies using a builder UI. After the recepie and it's ingredients have been filled out the app uses an external API to fetch nutrition data of each of the ingredients giving a prediction of the nutritional contents of the recipe.

## Calendar Planner. 
The calendar allowed the user to set recepies to certains dates which helped the user to plan their meals for each day.

## Nutrition Calculator. 
The calculator functionality on the other hand allowed users to take ingredients and get predictions of the nutritional contents based on their amounts. 

## Recepie Search. 
The Search function allowed users to search for existing recepies to add to their calendar for meal planning. The meals were fetched from another external API.
